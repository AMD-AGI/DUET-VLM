# DUET-VLM &mdash; project page

Static site for the CVPR 2026 paper, adapted from the
[Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Local preview

```bash
cd WEBSITE
python -m http.server 8080
# open http://localhost:8080
```

No build step &mdash; Bulma and Font Awesome load from a CDN.

## Hosting on GitHub Pages (`AMD-AGI/DUET-VLM`)

Pick one of the standard GitHub Pages flows:

**Option A &mdash; `/docs` folder on `main`** (simplest)
```bash
mv WEBSITE docs
git add docs && git commit -m "Add project page" && git push
# GitHub → Settings → Pages → Build from main, /docs
```

**Option B &mdash; dedicated `gh-pages` branch**
```bash
git subtree push --prefix WEBSITE origin gh-pages
# GitHub → Settings → Pages → Build from gh-pages, /
```

**Option C &mdash; serve directly from `WEBSITE/`**
GitHub Pages only accepts `/` or `/docs` as the source folder; if you keep the
`WEBSITE/` name you must use Option B (push that subtree to `gh-pages`).

In all three the site lands at:

> https://amd-agi.github.io/DUET-VLM/

## Drop-in assets

Put these files in `static/pdfs/` before publishing &mdash; the buttons in
`index.html` already point at them:

- `DUET_VLM.pdf` &mdash; camera-ready paper
- `DUET_VLM_poster.pdf` &mdash; poster export

The images under `static/images/` were copied from `POSTER/poster_assets/` and
are regenerated by `POSTER/build_poster.py`.
